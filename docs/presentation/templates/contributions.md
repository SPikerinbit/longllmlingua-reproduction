# contributions.md 个人段模板

每人一段，贴进根目录 `contributions.md`。不要用“负责协调、积极参与”这类句子。

```text
## 成员_（姓名以登记表为准）

阶段和大约份额：阶段_，约 25%。算法不是本人原创。

实际做了什么（每条对应一个路径）：
- 

个人运行路径（命令、配置、run_id、机器）：
- 

个人核验路径（不调用 API 的命令，或已有的 verification 文件）：
- 

提交包里由我写入的文件：
- 

AI 使用：写明用了什么工具、用在哪一段。没有就写没有。

我不负责、也不要算进我名下的结果：
- 
```
