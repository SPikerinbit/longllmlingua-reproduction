```text
节号和标题：
执笔 / 核验：
预算页数：

正文：
（每段至少一个数字或一条文件路径。）

图/表编号：
图题（含单位和样本范围）：
图文件：

本节省略、改由其他节承担的内容：

自查：
- [ ] 每个百分数都能在 01-number-registry.md 找到
- [ ] smoke 的 20 题和 pilot 的 100 题没有混用
- [ ] CUDA 的 83.2% 和 910B 的 82.6% 没有写成一次实验

```
