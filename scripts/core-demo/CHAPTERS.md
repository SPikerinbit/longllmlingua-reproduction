# 六章演示内容、停留建议与字幕

最终成片目标约 60 秒（每章约 8–12 秒）。原始录制请按阅读需要停，**不要用 sleep 人为拉长运算**。后期若变速，请在成品上标明速度，并把等待/停顿标为省略，而不是把计算时间加长。

所有数字和句子来自仓库文件或本次 CPU 实测。主体不是 77 项测试。

共用样本（阶段一完整预测，不是残缺 case 摘录）：

- 主链问题 `ef848352f36bc278ab99b295486d00f8fa68d2a26552caa8c12a67932b85b9fc`，位置 1，问句 *who was the first coronated king of manipur at kangla*，参考 Pakhangba / Pamheiba。
- 边界问题 `64a3debb5e078f5b6b41d180d4beb9288e39cb6ef737a178b56d56d3fbd644c5`，用于第 4 章误判/指标边界。

## 字幕建议（精简，可叠在成片上）

1. 入口与锁定配置：seed=42；20/100 题；金答案在第 1/5/10/15/20 位；七种方法。不是现场重跑全部实验。
2. 真实样本 20 篇文档；本例 gold 在第 1 位。答案和 isgold 不进入方法输入。
3. CPU 实测官方 BM25：3289→1644→822 token，与已存预测一致。4x 丢掉 gold 文档。本段不跑 Long（需要压缩权重）。
4. 已保存 DeepSeek 回答 + 官方首行评分。4x 不得分。否认句里仍出现答案词则得 1。拼成一行会改分，官方指标只用首行。
5. 已提交 CUDA 主比较：原始 84.6%，Long 2x 83.2%，差值 −1.4pp，区间跨 0。Long 4x 有 18/500 条超硬预算。
6. 已提交 NPU 消融：去掉粗粒度 82.6%→45.0%。效率上压缩没有带来端到端加速。77 项离线测试只是检查，不是这次实验。

不要出现「整个项目实验都在这 1 分钟里实时重跑」之类的说法。
